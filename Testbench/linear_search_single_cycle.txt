Linear search program for the normal single-cycle MIPS processor

C Pseudo code:
    int mem[6];
    mem[0] = 7;
    mem[1] = 3;
    mem[2] = 9;
    mem[3] = 5;
    mem[4] = 9;
    mem[5] = -1;

    for each array element:
        if (mem[i] == mem[4]) {
            mem[5] = i;
            break;
        }

Memory layout used by the testbench:

    memory[0] = arr[0] = 7
    memory[1] = arr[1] = 3
    memory[2] = arr[2] = 9
    memory[3] = arr[3] = 5
    memory[4] = key    = 9
    memory[5] = result = -1 initially, 2 after successful search

Single-cycle assembly:

        addi $s0, $zero, 0
        lw   $t7, 16($s0)
        lw   $t0, 0($s0)
        beq  $t0, $t7, FOUND0
        lw   $t1, 4($s0)
        beq  $t1, $t7, FOUND1
        lw   $t2, 8($s0)
        beq  $t2, $t7, FOUND2
        lw   $t3, 12($s0)
        beq  $t3, $t7, FOUND3
        addi $t6, $zero, -1
        sw   $t6, 20($s0)
        j    END

FOUND0:
        addi $t6, $zero, 0
        sw   $t6, 20($s0)
        j    END

FOUND1:
        addi $t6, $zero, 1
        sw   $t6, 20($s0)
        j    END

FOUND2:
        addi $t6, $zero, 2
        sw   $t6, 20($s0)
        j    END

FOUND3:
        addi $t6, $zero, 3
        sw   $t6, 20($s0)

END:
        add  $zero, $zero, $zero
